# Implementação Black Market

Angular standalone e OnPush existentes; preservar signals, inputs e contratos. Ler `angular-developer` para a API específica usada. Tailwind v4 já existe: centralizar tokens CSS e preservar SCSS enquanto consumidores permanecerem.

Usar Brain para comportamento e Helm copiado para aparência. Antes de criar primitiva, consultar `spartan` e o inventário `ng g @spartan-ng/cli:info --json`. Customizações BDO pertencem aos arquivos Helm e aos tokens semânticos, nunca a node_modules. Registrar versão CLI e diffs locais antes de atualizar componentes.

Cards e inputs devem compartilhar borda, raio, altura e foco. Bronze identifica títulos/seleção; carvão é superfície. Ícones do catálogo continuam sendo domínio; Lucide atende ações de interface. Sem wrappers quando diretivas existentes resolvem.
