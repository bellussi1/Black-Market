# Inventário visual

Prioridade inicial: controles compartilhados, shell e receitas. O workspace de receitas usa SCSS extenso, botões nativos e painel de detalhes; árvore especializada preserva pan, zoom e seleção. Mercado, armazém, família, OCR e recomendações constituem as próximas features.

Tokens BDO e Tailwind convivem. Há skill `bdo-ui-design` com identidade visual específica. A nova skill geral deve conter princípios do PDF e remeter à skill BDO para decisões de tema.

Pendências confirmadas pelo usuário: retirar modo avançado; manter configurações em seu contexto; padronizar cards e campos; três ações de cenário (comprar, produzir/coletar toda cadeia, otimizar); usar cotações recentes da API sem edição de preço. Não transformar dados ausentes em lucro confirmado.
