# Fila de implementação — Black Market

Esta é a fila persistente do projeto. Não há uma ferramenta de fila/Queue conectada a esta conversa; as instruções ficam registradas aqui para manter ordem e critérios no repositório. ## Instruções anteriores já registradas fora da fila de implementação

Segurança/infraestrutura, logs/erros/health, páginas legais/footer, base de analytics, SEO básico e auditoria de produção têm documentação e código no projeto. A fila os coloca em revalidação quando a ordem 3 for executada; não indica que integrações externas, revisão jurídica, Lighthouse em produção ou alertas por credenciais já estejam concluídos.

O roadmap de produto em [roadmap.md](roadmap.md) contém ordem por uso esperado, entregas, riscos e critérios de validação para o conjunto de funcionalidades. Este arquivo é a ordem de execução, não uma declaração de que itens do backlog já estão prontos.
